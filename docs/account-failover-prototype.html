Account backups for a workspace

Orca Flow UX draft · fixture identities only · nothing here reads accounts or touches Orca

Recommendation

Ask at the first limit. Manage in workspace settings. In Usage, show only status.

  • The first limit is when the cost is real. The person can see which conversation would move, to which login, and that the login will receive its history. Nothing is set up beforehand, so there are no groups by default.
  • Continue on … applies once. Do this automatically for Atlas creates the workspace group. It is off by default.
  • Workspace settings is the lasting home. It shows both providers per workspace, with order, revoking and re-approving. Every continuation receipt links there.
  • No consent control in the Usage menu. Clicking an account row there changes the host default for new launches, so a workspace checkbox next to it suggests the wrong scope. Usage shows only which account Atlas is using now.

Same in every placement

  • Consent is per managed login, never per System default. System default appears only as a note on the login it currently points to (“also System default”).
  • A temporary error never changes accounts. An unknown limit scope keeps the work in place. An organization limit skips the logins in that organization.
  • Each login is tried at most once per limit. When none is left, there is one waiting line with the earliest reset and Check now.
  • Continuation status is one line in the conversation, a subtitle on the Flow card and an “Atlas” tag in Usage. Proof (account, session, model, role) appears under Details.
  • On Orca 1.4.272 nothing new appears. Work continues in its conversation after the reset.

Open for the user

  • Placement: pick one of the three, or use the recommended mix.
  • Should work move back to the original login after its reset? The contract doesn’t say, and the draft promises nothing.
  • Should Do this automatically start checked once the person has picked the same backup twice?
  • Unattended workers: is a “Needs you” card enough, or should the coordinator also get mail?
